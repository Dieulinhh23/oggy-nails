# Oggy Nails

Independent, responsive salon website inspired by playful cyan, cobalt, cherry red, and cartoon shapes. Adapted from the service menu of Nailbook; does not connect to its database or share customer records.

Run `npm run dev` and open http://localhost:8081. Run `npm run build` to validate the static files. Deploy `dist/` to any static host.

Includes category filters, a full service menu, inspiration gallery, and an appointment request planner. Requests are saved only in the visitor's browser; they are not sent to a salon or confirmed. Contact information, staff availability, and a booking backend must be configured before accepting real appointments. Prices are an illustrative starter menu.
